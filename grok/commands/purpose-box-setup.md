# Purpose Box setup

Install the Purpose Box always-on rule so it applies from your next session onward.

Do this now, in order:

1. Create the folder `~/.grok/rules/` if it does not already exist.
2. Copy this plugin's `rules/purpose-box.md` file into `~/.grok/rules/purpose-box.md`. If a file already exists at that path, **overwrite it** — do not create a second copy or rename either file.
3. Confirm to the user in a single line that Purpose Box is installed and will take effect starting next session.

Do not skip step 2's overwrite behavior: `~/.grok/rules/purpose-box.md` must always end up holding exactly the content of this plugin's `rules/purpose-box.md`, and only one file of that name should exist.
